### 🚀 Projetos Apresentados

### ⚽ Simulador do Brasileirão em Python
Sempre gostei de futebol e de programação, então resolvi juntar os dois em um projeto prático. Criei um simulador do Campeonato Brasileiro em Python! O programa roda e gerencia toda a dinâmica da competição:
- **Registrar partida:** Registra uma partida manualmente.
- **Mostrar tabela:** Tabela do campeonato atualiza automaticamente pontos, jogos, vitórias, empates, derrotas, gols pró/contra e saldo de gols.
- **Zonas de Classificação:** Mapeamento automático de vagas para a Libertadores, Pré-Libertadores, Sul-Americana e Zona de Rebaixamento.
- **Estatísticas:** Consulta individual de aproveitamento e médias de gols por time.
- **Histórico:** Registro de todas as partidas disputadas na temporada.

*Projeto simples, mas excelente para treinar manipulação de dicionários, listas, funções e lógica em Python.*

### 📞 Central de Atendimento em Java
Desenvolvido para a disciplina de Estruturas de Dados I, este projeto simula uma central de atendimento para gerenciar a fila e a prioridade dos chamados recebidos:
- **Gerenciamento de Filas:** Organização de atendimentos com base nas estruturas de dados aprendidas na prática.
- **Controle de Prioridades:** Lógica aplicada para classificar e direcionar atendimentos prioritários e convencionais.
- **Fluxo de Atendimento:** Registro, processamento e encerramento dos chamados da central.

*Ótimo projeto para consolidar conceitos de orientação a objetos e estruturas de dados fundamentais em Java.*

### 🍱 Minha Refeição (Protótipo UI/UX no Figma)
Projeto focado em Design de Interface (UI) e Experiência do Usuário (UX) para um aplicativo mobile de entrega de marmitas:
- **Fluxo de Navegação:** Criação do mapa da aplicação, desde a escolha da refeição até a tela de confirmação do pedido.
- **Protótipo Interativo:** Telas interativas construídas no Figma para simular a experiência real de uso do usuário.

*Excelente exercício para desenvolver o pensamento centrado no usuário e metodologias de design no Figma.*
